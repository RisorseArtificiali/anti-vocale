# Руководство пользователя Anti-Vocale

Anti-Vocale распознаёт голосовые сообщения на вашем устройстве Android полностью офлайн. Аудио никогда не покидает ваш телефон: распознавание идёт локально на открытых ИИ-моделях, без аккаунта, без облачного сервиса и без телеметрии.

Руководство обновлено для версии 1.11.

## Начало работы

1. Установите Anti-Vocale из своего магазина приложений (Google Play или F-Droid) или из APK-файла со страницы релизов на GitHub.
2. Откройте приложение один раз. На вкладке **Модели** вы увидите встроенные модели, доступные для скачивания.
3. Скачайте одну модель. Для большинства пользователей рекомендуемая первая модель: **Parakeet TDT (stock int8, 464 МБ)**. Она быстрая, компактная и охватывает 25 европейских языков.
4. Чтобы распознать сообщение, поделитесь голосовым сообщением из любого мессенджера (WhatsApp, Telegram, Signal и другие) с Anti-Vocale. Во время обработки появится уведомление, а затем второе уведомление с текстом.
5. Нажмите на уведомление с результатом, чтобы скопировать текст, поделиться им или отправить обратно в тот чат, откуда пришло голосовое сообщение.

Дальнейшая настройка не требуется. Всё, что описано ниже, необязательно.

## Выбор модели

Модели различаются размером, скоростью, набором языков и точностью. Вкладка «Модели» показывает ключевые факты на каждой карточке ещё до скачивания. Краткий ориентир:

| Модель | Размер | Языки | Примечания |
|---|---|---|---|
| Parakeet TDT stock int8 | 464 МБ | 25 европейских | Быстрая и лёгкая; рекомендация по умолчанию |
| Parakeet TDT SmoothQuant | 862 МБ | 25 европейских | Точнее, но тяжелее; требует больше памяти |
| Whisper Turbo | 988 МБ | 101 | Лучший баланс в семействе Whisper |
| Whisper Medium | 903 МБ | 101 | Медленнее Turbo, для большинства аудио не лучше |
| Whisper Small | 358 МБ | 101 | Самая лёгкая из Whisper; достойное качество |
| Whisper Distil Italian | 938 МБ | только итальянский | Лучшая точность для итальянского среди встроенных |
| Qwen3-ASR | 938 МБ | многоязычная | Альтернативная архитектура |
| Nemotron streaming | 640 МБ | многоязычная | Показывает текст по мере речи (потоковое распознавание) |
| GigaAM v3 | 326 МБ | русский | Специалист по русскому |

Общие ориентиры:
- Если вы распознаёте в основном один язык, специализированная модель (Distil Italian, GigaAM) выигрывает у универсальной модели того же размера.
- Если на телефоне 4 ГБ оперативной памяти или меньше, выбирайте модели меньше 500 МБ.
- Модели Gemma (они перечислены на вкладке «Модели» отдельно) это большие языковые модели, которые тоже умеют распознавать речь. Они интересны для экспериментов, но тяжелее и медленнее специализированных моделей распознавания.

## Распознавание: повседневная работа

- Поделитесь голосовым сообщением с Anti-Vocale. Обработка начинается сразу, даже при выключенном экране.
- Уведомление с результатом предлагает: **Копировать**, **Поделиться** и, если исходное приложение поддерживается, **Отправить в [Приложение]**; текст вставляется прямо в чат, откуда пришло голосовое сообщение.
- С включённым автокопированием (Настройки) текст уже находится в буфере обмена к моменту появления уведомления; уведомление об этом сообщает.
- Каждое распознавание сохраняется на вкладке **История** с указанием модели, длительности и времени обработки. Долгое нажатие на запись позволяет повторить распознавание, скопировать, удалить запись или сообщить о плохом результате по электронной почте.
- С автосохранением в папку (Настройки) каждый результат также записывается как файл .txt в выбранную вами папку.

## Длинные записи, очередь и повторные попытки

- Любая длительность аудио работает с любой моделью: длинные записи автоматически разбиваются и склеиваются. (В старых версиях для Parakeet существовал лимит 6:40; его больше нет.)
- Поделитесь несколькими сообщениями подряд: они встанут в очередь. Каждый элемент очереди можно отменить отдельно из его уведомления, пока идёт другое распознавание.
- Неудавшееся распознавание можно повторить одним нажатием на вкладке «История».

## Модели сообщества и импорт

Встроенный каталог охватывает не все языки. Anti-Vocale поставляется с каталогом моделей сообщества, которые импортируются за два касания: вкладка «Модели», раздел «Дополнительно», ONNX Sherpa, «Импорт из каталога», фильтр по вашему языку, выбор модели, подтверждение. Сейчас среди моделей сообщества: арабский (диалекты), русский, испанский, немецкий (потоковая) и швейцарский немецкий.

Опытные пользователи также могут:
- импортировать модель по URL репозитория Hugging Face или по ссылке на запись каталога (расширенный раздел в том же диалоге);
- импортировать набор файлов модели из папки на телефоне;
- указать приложению другой индекс каталога (действие «изменить» рядом с источником каталога); его может вести кто угодно, например ваше сообщество.

Формат импорта и требования к файлам описаны в документе [внешние модели](../../external-models.md).

## Tasker и автоматизация

Anti-Vocale принимает broadcast (широковещательное сообщение), который может отправить Tasker или любое приложение автоматизации, чтобы распознать файл без работы с интерфейсом:

```
Action: com.antivocale.app.PROCESS_REQUEST
Extras: request_type=audio, file_path=/path/to/audio, task_id=your-id
Optional: backend_id=<model id> to pick the model for that request
```

Результат возвращается ответным broadcast. Подробное пошаговое руководство с примерами находится в [гайде по Tasker](../../TASKER_GUIDE.md).

## Настройки по приложениям

Для каждого приложения, из которого вы делитесь аудио (WhatsApp, Telegram, ...), настраивается отдельно: показывать ли действие «Быстрый ответ» (отправку текста обратно в чат), включать ли автокопирование и какой звук уведомления использовать. Вкладка «Настройки», «Настройки по приложениям».

## Конфиденциальность

- Распознавание на 100 % происходит на устройстве. Ни аудио, ни текст, ни метаданные никогда не покидают ваш телефон.
- Для распознавания у приложения нет доступа в интернет; сеть используется, только когда вы сами скачиваете модель.
- История хранится на вашем устройстве и принадлежит вам: очистить её можно в любой момент на вкладке «История».
- Версия из Play включает отчёты о сбоях Crashlytics (их видно и можно отключить в настройках Android); в версии F-Droid их нет.

## Устранение неполадок

**Распознавание не завершается / уведомление исчезает.**
Некоторые производители телефонов (Vivo, OPPO, некоторые Xiaomi и Samsung) агрессивно приостанавливают фоновые приложения. Откройте Anti-Vocale один раз и, если приложение предложит, разрешите работу в фоне; или найдите приложение в настройках батареи и выберите «Без ограничений». Приложение распознаёт такую ситуацию и объясняет её в уведомлении, когда это происходит.

**«Недостаточно памяти» или сбои с большими моделями.**
Размер модели указан на карточке. На телефонах с 4 ГБ оперативной памяти или меньше используйте модели меньше 500 МБ. Если распознавание завершается ошибкой нехватки памяти, попробуйте более короткий файл, более компактную модель или закройте другие приложения.

**Качество распознавания низкое.**
Попробуйте специализированную модель для вашего языка (см. таблицу выше). Нажмите и удерживайте неудачную запись в «Истории» и выберите «Сообщить об ошибке в тексте», чтобы отправить нам подробности (модель, длительность, время обработки; фрагмент текста только по вашему желанию).

**Приложение падает при включённом NNAPI.**
Если вы включили провайдер NNAPI в настройках и приложение стало закрываться, при следующем запуске оно автоматически вернётся к CPU. Работа NNAPI сильно зависит от чипсета телефона; если сбои повторяются, оставьте CPU.

## Часто задаваемые вопросы

**Работает ли приложение без интернета?**
Да. После скачивания модели распознавание полностью работает офлайн.

**Какие мессенджеры поддерживаются?**
Любое приложение, которое может поделиться аудиофайлом. Отправка текста обратно в чат сейчас поддерживается для части приложений (WhatsApp, Telegram и других, определяемых автоматически).

**Где мои результаты?**
На вкладке «История» и, если включено, в виде файлов .txt в выбранной вами папке. Больше нигде ничего не хранится.

**Можно ли автоматически распознавать голосовые сообщения по мере поступления?**
Пока нет. Это в планах; сейчас достаточно одного касания, чтобы поделиться.

**Почему магазина два (Play и F-Droid)?**
Это одно и то же приложение с теми же функциями. F-Droid собирает его из исходного кода без проприетарных компонентов; версия из Play добавляет автоматические отчёты о сбоях.

**Это действительно приватно?**
Да. Исходный код открыт; вы можете убедиться, что никакие данные не покидают устройство. См. политику конфиденциальности в репозитории.
