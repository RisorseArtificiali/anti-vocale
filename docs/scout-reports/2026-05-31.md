# Model Scout Report — 2026-05-31

## Executive Summary

Significant update since last report (2026-05-29). **NVIDIA released Nemotron-3.5-ASR-Streaming-Multilingual-0.6b** — a new 0.6B-param streaming RNNT model supporting 7 languages including Italian, with an existing ONNX INT4 community conversion. This is the first streaming-capable multilingual ASR model with Italian support in the ONNX ecosystem. Also: csukuangfj exported Omnilingual ASR v2 to sherpa-onnx (1600+ languages, CTC, 235MB–688MB), Mistral's Voxtral Mini 4B streaming ASR appeared (1.18M downloads, no Android path yet), and Silero VAD v5 is now available in LiteRT at 1.26MB. PR #3617 (ORT override) remains merged but no new sherpa-onnx release yet.

## ASR Model Findings

### nvidia/nemotron-3.5-asr-streaming-0.6b (BREAKTHROUGH)
- **Source:** https://huggingface.co/nvidia/nemotron-3.5-asr-streaming-0.6b
- **ONNX conversion:** https://huggingface.co/nenad1002/NVIDIA-Nemotron-3.5-ASR-Streaming-Multilingual-0.6b-onnx-int4
- **Size:** 0.6B params; ONNX INT4 conversion includes encoder + decoder + joint + silero_vad
- **Languages:** en, es, fr, **it**, pt, de, zh (7 languages, including Italian)
- **Last updated:** 2026-05-31 (brand new)
- **Downloads:** 201 (official), community ONNX conversion has bundled VAD
- **Format:** NeMo (.nemo) official; ONNX INT4 community conversion exists
- **sherpa-onnx compatible:** Not yet packaged by csukuangfj, but the ONNX INT4 structure (encoder/decoder/joint + vocab.txt/tokenizer.json) follows standard NeMo transducer conventions. Likely adaptable.
- **Italian quality assessment:** Not independently benchmarked. Based on NeMo FastConformer RNNT architecture (same family as Parakeet). Streaming capability is the key differentiator. 7 languages is a narrower set than Parakeet v3's 25, but covers major EU languages.
- **Score:** 8.5/10 (Italian quality: 8 — same architecture family proven for Italian, Size: 8 — 0.6B competitive, On-device: 9 — streaming + ONNX INT4, Multilingual: 5 — only 7 languages, Maintenance: 9 — NVIDIA official)
- **Recommendation:** **evaluate urgently** — first streaming multilingual ASR with Italian in ONNX ecosystem. If sherpa-onnx integration is feasible, this could enable real-time transcription with progressive display.
- **Effort to integrate:** medium — need to verify ONNX INT4 compatibility with sherpa-onnx's NeMo transducer config, test streaming inference, add model download. The bundled Silero VAD is a bonus for segmentation.
- **Notes:** Gated model (requires access request). Streaming architecture allows processing audio in chunks with state caching, enabling progressive display without waiting for full audio. This directly addresses the streaming limitation identified in our VAD+Whisper segmentation research.

### csukuangfj2/sherpa-onnx-omnilingual-asr-1600-languages-*-ctc-v2-*
- **Source:** Multiple variants on HuggingFace (csukuangfj2)
- **Size:** 300M INT8 ~235MB, 1B INT8 ~688MB, 1B INT4 ~525MB
- **Languages:** 1600+ including Italian
- **Last updated:** 2026-02-05 (v2)
- **Format:** ONNX CTC, sherpa-onnx native (`--omnilingual-asr-model` flag)
- **sherpa-onnx compatible:** Yes — natively supported
- **Italian quality assessment:** CTC models produce character-level output without punctuation or casing. v2 reportedly improves over v1. 300M variant likely weaker than our Parakeet/Whisper models. 1B variant may be competitive but is larger.
- **Score:** 5/10 (Italian quality: 4 for 300M, 6 for 1B — CTC limitation, Size: 9 for 300M, 6 for 1B, On-device: 9, Multilingual: 10, Maintenance: 7)
- **Recommendation:** **watch** — the 300M at 235MB is appealing for size but CTC quality is a real limitation. The 1B at 525-688MB is more competitive but doesn't beat Parakeet for Italian. Interesting as a fallback or for exotic language support beyond our 25-language set.
- **Effort to integrate:** low — sherpa-onnx already supports it
- **Notes:** 40-second max audio length for CTC variant. Would need chunking for longer voice messages.

## Landscape Developments

**NVIDIA Nemotron-3.5-ASR-Streaming** represents a significant shift in the on-device ASR landscape. For the first time, there is a streaming-capable multilingual RNNT model at mobile-friendly scale (0.6B) with Italian support and an ONNX conversion path. This directly addresses the limitation identified in our streaming transcription research: Whisper can't stream, and Parakeet's streaming variants were English-only. If Nemotron-3.5-ASR integrates into sherpa-onnx, it would enable real-time progressive display of transcription results.

**soniqo.audio ecosystem** is producing comprehensive LiteRT (TFLite) exports of ASR models specifically for Android — Parakeet, Omnilingual ASR, Nemotron Speech, Silero VAD v5, and Pyannote segmentation. This represents a growing TFLite-first deployment path that could complement or eventually replace ONNX Runtime for some models.

**Voxtral (Mistral)** shows that streaming multilingual ASR is a hot area — 1.18M downloads for Voxtral Mini 4B indicates strong demand. The lack of Android ONNX export is a gap that the community will likely fill.

**Omnilingual ASR v2 in sherpa-onnx** provides 1600+ language coverage at very small sizes (235MB for 300M INT8). CTC quality is the trade-off, but for exotic language support beyond our 25-language Parakeet set, this is now a drop-in option.
