### cubicleai/Parakeet-EOU-120M-ONNX / cubicleai/Parakeet-EOU-120M-ONNX-Q8
- **Source:** https://huggingface.co/cubicleai/Parakeet-EOU-120M-ONNX
- **Size:** ~120M params (small)
- **Languages:** Language-independent (end-of-utterance detection, not transcription)
- **Last updated:** 2026-05-27
- **Format:** ONNX (full + Q8 quantized)
- **sherpa-onnx compatible:** Uncertain — EOU detection is a different task than transcription
- **Score:** 4/10 (as VAD component: Italian quality: N/A, Size: 9, On-device: 8, Multilingual: 10, Maintenance: 4)
- **Recommendation:** **watch** — EOU detection could replace or augment Silero VAD for better voice message segmentation. A 120M ONNX model is very lightweight. Would need custom integration pipeline.
- **Effort to integrate:** medium — new inference component alongside existing ASR pipeline
- **Notes:** End-of-utterance detection determines when a speaker has finished talking. More accurate than energy-based VAD for segmentation decisions. Could improve our streaming/chunking strategy.
