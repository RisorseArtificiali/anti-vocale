# Model Scout Report — 2026-05-14

## Executive Summary

One day since last report. **sherpa-onnx v1.13.2 released yesterday** with Parakeet streaming infrastructure and NeMo beam search bug fix — upgrade recommended. **Parakeet TDT 0.6b v3 now has official TFLite builds** with device-specific variants for Snapdragon/MediaTek/Exynos/Tensor, plus a community ONNX split conversion. **Cohere Transcribe sherpa-onnx conversion deliberately excludes Italian** (9/14 languages) — a significant negative finding. No new Italian ASR models. No Whisper v4. All tracked blocked items remain unchanged (VibeVoice stale, llama-bro 50 days inactive, GGUF audio path blocked).

## ASR Model Findings

### litert-community/parakeet-tdt-0.6b-v3
- **Source:** https://huggingface.co/litert-community/parakeet-tdt-0.6b-v3
- **Size:** TFLite int8 (multiple device-specific builds)
- **Languages:** 25 European languages (same as our Parakeet TDT v3 ONNX)
- **Last updated:** 2026-05-13
- **Format:** TFLite (f32 + int8, generic + device-specific)
- **sherpa-onnx compatible:** No — TFLite format, different runtime
- **Italian quality assessment:** Same model as our ONNX Parakeet TDT v3 — ~5.4% WER on clean Italian, ~10.1% on real WhatsApp audio
- **Score:** 7.0/10 (Italian quality 4/5, small model 4/5, requires TFLite runtime 3/5, 25 langs 5/5, active 5/5)
- **Recommendation:** **evaluate** — Device-specific NPU builds (Qualcomm SM8550-SM8850, MediaTek, Exynos, Tensor G5) could offer significant speedup over our ONNX CPU inference. The int8 TFLite builds are likely faster than our int8 ONNX on compatible SoCs. Would require TFLite runtime integration or using LiteRT-LM.
- **Effort to integrate:** Medium — need TFLite inference path alongside sherpa-onnx, or replace for devices with compatible SoCs
- **Notes:** 1,389 downloads. Apache-2.0. Includes stateful streaming variants (5s context). Device builds: Google Tensor G5, MediaTek MT6877/6878/6879/6897/6983/6985/6993, Qualcomm SM8450/8550/8650/8750/8850, Samsung Exynos 2400/2400e/5400. The Realme RMX3853 likely uses a Snapdragon 7 Gen 2 or similar — need to verify SoC compatibility.

## Landscape Developments

**Streaming transducer maturation:** sherpa-onnx v1.13.2 formalizes the `buffered_nemo_rnnt` streaming path with configurable chunk sizes (240/560/1120ms). The infrastructure is production-grade. A multilingual Parakeet TDT v3 streaming variant would be the ideal model for Anti-Vocale's VAD+segmentation architecture.

**Cohere Transcribe Italian gap:** csukuangfj's sherpa-onnx conversion covers only 9/14 languages. Italian is deliberately excluded — the test_wavs directory confirms the supported set (AR, DE, EN, ES, FR, JA, KO, VI, ZH). This suggests integration difficulties with the Italian language adapter or tokenizer. The only ONNX conversion including Italian (christopherthompson81) uses a custom decoder loop format incompatible with sherpa-onnx.

**Qwen3-ASR 1.7B blocked:** GitHub issue #3535 reveals that csukuangfj cannot publish the 1.7B int8 model because GitHub's 2GB file size limit blocks the upload. HuggingFace publication was suggested but not actioned. The 1.7B variant (potentially better Italian quality) is unlikely to appear as a sherpa-onnx pre-converted model.

**No Whisper v4:** OpenAI has not released Whisper v4. Latest remains `whisper-large-v3-turbo` (2024-10-04). Community "whisper v4" LoRA experiments exist but are personal projects.
