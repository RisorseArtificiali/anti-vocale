## Landscape Developments

**Conversational Speech Recognition (CSR):** Deepgram introduced Flux Multilingual (April 29) supporting Italian among 10 languages. This is a cloud API — not on-device — but defines a new ASR category focused on dialogue understanding, not just transcription.

**Non-autoregressive ASR acceleration:** SenseVoice demonstrated 52x speedup over Whisper using non-autoregressive architecture (parallel decoding instead of token-by-token). Limited to 5 CJK languages but the pattern is emerging as the future direction for latency-critical ASR. If extended to multilingual models, this could dramatically improve our on-device speed.

**On-device runtime consolidation:** Four runtimes dominate: TFLite/LiteRT, ONNX Runtime, Core ML, ExecuTorch 1.0. NPUs are 40-60x more efficient than GPUs for single-inference workloads. Google's official LiteRT Parakeet exports signal TFLite becoming the preferred Android ASR runtime.

**Microsoft Phi-4-multimodal:** 5.6B params, 6.14% WER on OpenASR leaderboard, designed for edge. No ONNX/litertlm format yet — worth watching.
