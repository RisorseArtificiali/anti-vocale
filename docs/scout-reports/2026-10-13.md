# Model Scout Report: 2026-10-13

Scope: full (ASR, LLM, frameworks, parakeet, whisper, qwen, Italian reference sweep).
Baseline verified this run: sherpa-onnx v1.13.8 (`.sherpa-version`, srclib 11afbd0),
LiteRT-LM 0.17.1 (`gradle/libs.versions.toml`), community catalog
`app/src/main/assets/external-catalog/index-1.15.0.json` (30 entries).
Previous reports: 2026-10-08 (LiteRT-LM 0.18.0 verdict), 2026-10-06 (zh/fi/ar), 2026-09-30 (full).

## Executive Summary

One headline finding: **Moondream Parakeet Ultra**, a post-trained parakeet-tdt-0.6b-v3
(same architecture, same tokenizer, 25 languages) that beats v3 on every published
benchmark group, including Italian FLEURS WER 2.61 -> 2.00 and background-noise WER
6.72 -> 5.82, with an int8 sherpa-onnx conversion already on HuggingFace whose config is
identical to our built-in Parakeet entry (nemo_transducer, 128 mels, sherpa >= 1.13.8).
This is the first credible quality upgrade to our multilingual backbone since we shipped
v3, reachable either as a community-catalog entry (no app release) or as a built-in
variant swap, gated on an eval-harness A/B. Secondary finds: a Greek Parakeet fine-tune
that fixes v3's real Greek tokenizer defects (missing final sigma, Latin drift), a
smaller Omnilingual v2 conversion (235MB int8 vs the 365MB v1 we catalog), Microsoft's
VibeVoice-ASR-BitNet as a second Italian-capable .litertlm candidate on our shipped
LiteRT-LM lane, and the BuzzASR 102-language suite as a long-tail coverage resource.
No new sherpa-onnx tag (still v1.13.8) and no change to the LiteRT-LM stay-on-0.17.1
verdict.

## ASR Model Findings

### Moondream Parakeet Ultra (+ int8 sherpa-onnx conversion)
- **Source:** https://huggingface.co/moondream/parakeet-ultra (base);
  https://huggingface.co/Alexqwqw/parakeet-ultra-sherpa-onnx-int8 (sherpa conversion,
  2026-10-12); independent second conversion with byte-identical file sizes:
  https://huggingface.co/tpmaerk/parakeet-ultra-sherpa-onnx-int8; ONNX by mrfakename:
  https://huggingface.co/mrfakename/parakeet-ultra-ONNX
- **Size:** ~670 MB int8 (encoder 652 MB + decoder 11.8 MB + joiner 6.4 MB + tokens);
  base safetensors 1.26 GB
- **Languages:** same 25 European languages as parakeet-tdt-0.6b-v3 (incl. it, ru, el, uk)
- **Last updated:** base ~2026-09-30; conversions 2026-10-05..12
- **Format:** ONNX int8 (offline NeMo TDT transducer: encoder/decoder/joiner/tokens.txt)
- **sherpa-onnx compatible:** yes. The conversion card targets sherpa-onnx >= 1.13.8
  (our exact pin) with `model_type="nemo_transducer"`, `feature_dim=128`, and
  `tokens.txt` identical to the v3 vocabulary (8192 BPE + blank)
- **Import path:** community catalog (TRANSDUCER family, entry-JSON shape proven) AND
  built-in candidate (drop-in Parakeet variant swap)
- **Quality assessment:** published by moondream on their pipeline (Photon, NVIDIA GPU,
  Open ASR Leaderboard normalizers): Open ASR Leaderboard EN 6.26 -> 5.80; FLEURS
  25-lang 11.62 -> 9.55; business speech 6.15 -> 5.79; MUSAN noise 6.72 -> 5.82;
  TED-LIUM long-form 2.71 -> 1.94. Italian FLEURS row: 2.61 -> 2.00. These are fp16 GPU
  numbers; the int8 mobile conversion is NOT yet validated by anyone on device. Our own
  Italian baselines (eval harness, 11-clip clean set par = 3.1%; real-WhatsApp ~10.1%)
  are the gate, not these. Confidence: model quality HIGH (three benchmark groups,
  consistent); on-device int8 quality UNVERIFIED.
- **Score:** 8.4/10 (quality 4, size 4, feasibility 5, coverage 3, catalog-import 5,
  maintenance 4)
- **Recommendation:** evaluate immediately: download the Alexqwqw int8 package, run the
  eval-harness A/B against our pinned v3 (clean set + real WhatsApp clips), then a
  device-validation pass; if it wins, ship as a catalog TRANSDUCER entry first
  (release-free) and consider the built-in swap at the next release
- **Effort:** low (eval) / low-medium (catalog entry: same family, same modelType, files
  exist; needs the REQUIRED device-validation pass) / medium (built-in variant: catalog
  pin, sha256, size budget)
- **Notes:** same tokenizer means the app's language-offer machinery and configs keyed
  on Parakeet stay valid. Noise robustness (+0.9 WER on MUSAN) matters more for our
  real-world voice-note audio than the clean FLEURS delta. Watch for a csukuangfj
  official conversion to replace the community one before pinning hashes.

### Moondream Parakeet Redux (ternary sibling)
- **Source:** https://huggingface.co/moondream/parakeet-redux
- **Size:** 178 MB (1.58-bit ternary encoder)
- **Languages:** same 25 as v3
- **Last updated:** ~2026-09-30
- **Format:** packed ternary weights, read by moondream's Photon runtime only
  (CoreML/GGUF community conversions exist; none readable by sherpa-onnx)
- **sherpa-onnx compatible:** no (sherpa has no ternary kernel; de-ternarizing to int8
  would erase the 178MB advantage)
- **Import path:** none today
- **Quality assessment:** FLEURS 25-lang 10.56 (BETTER than v3's 11.62), long-form 2.51
  (better), English 6.55 (slightly worse), noise 9.04 (clearly worse). Published by
  moondream, same pipeline as Ultra.
- **Score:** 5.8/10 (quality 3, size 5, feasibility 1, coverage 3, catalog-import 1,
  maintenance 4)
- **Recommendation:** watch. If sherpa-onnx ever grows ternary weight support or an
  equivalent-quality ONNX export appears, this is a 178MB 25-language row that would
  become our default low-RAM Parakeet
- **Effort:** n/a (blocked on runtime)
- **Notes:** the noise regression (9.04 vs 6.72) makes it a poor fit for voice-note audio
  even if a runtime path appears; its role would be the low-RAM tier.

### Parakeet TDT 0.6B Greek / Cypriot Greek (myned-ai)
- **Source:** https://huggingface.co/myned-ai/parakeet-tdt-0.6b-v3-greek (2026-10-11)
- **Size:** 0.6B class, ONNX present (int8 size not stated on card; expect ~650MB class)
- **Languages:** el (Greek + Cypriot Greek)
- **Last updated:** 2026-10-11
- **Format:** NeMo fine-tune, ONNX files present; sherpa-layout conversion NOT confirmed
- **sherpa-onnx compatible:** uncertain (TDT fine-tune so the nemo_transducer path
  applies, but the repo ships nemo/onnx, not a verified sherpa package; the vocabulary
  was MODIFIED vs v3, tokens must ship with the model)
- **Import path:** community catalog (TRANSDUCER family) after a sherpa-layout
  conversion and device validation
- **Quality assessment:** card documents concrete v3 Greek defects it fixes: v3 has no
  final sigma in its vocabulary and drops it, never writes the Greek question mark,
  drifts into Latin letters or the wrong language on short clips (examples: Greek one-word
  clips fall from 29% to 6% error; a Cypriot clip decoded by v3 as English). Claims lower
  error than Whisper large-v3 on every Greek set run, 26% WER on unseen Cypriot speakers
  (vs 47% for whisper-large-v3), trained on 2,087h. Confidence: MEDIUM (self-published
  tables with examples, no third-party benchmark; but the defect pattern it fixes is
  specific and checkable in minutes with our harness).
- **Score:** 7.2/10 (quality 4, size 4, feasibility 3, coverage 4, catalog-import 3,
  maintenance 3)
- **Recommendation:** stage for the catalog if Greek demand appears: Greek is v3's
  weakest covered language (FLEURS el 35.71/32.25 v3/ultra) and this fixes
  tokenizer-level failures, not just WER
- **Effort:** medium (sherpa-layout conversion of a transducer family model is UNPROVEN
  in our pipeline; the community-model-conversion skill is proven on Whisper only)
- **Notes:** the modified vocabulary would also need the import-metadata validation to
  accept it; check `ModelFamilySupport` token-file rules first.

### BuzzASR: 102 monolingual Whisper large-v3 fine-tunes
- **Source:** https://huggingface.co/BuzzASR (org; 100+ models, e.g. BuzzASR/italian);

- **Languages:** 102, weighted to long-tail: zulu, wolof, xhosa, somali, luo, luganda,

  Whisper pipeline

## Landscape Developments

- **Moondream entered on-device speech** with Parakeet Redux/Ultra (2026-09-30): a
  post-training + ternary-compression pair on NVIDIA's Parakeet v3, with their own
  Photon runtime. The significant part for us: they publish full per-language FLEURS
  tables against the base model, and the Ultra checkpoint is a plain NeMo TDT that any
  ONNX exporter can take. Expect this line to keep moving (their release post frames
  speech as a long-term investment).
- **Qwen3-ASR-1.7B (Jan 2026)** continues to accrue community fine-tunes (Cantonese LoRA,
  Korean, Darija, Bengali) and now has multiple independent ONNX exports; the mobile
  int8 packaging is still missing. The 1.7B tier is becoming the quality ceiling of the
  Qwen line for built-in consideration once a proper package appears.
- **BuzzASR (EMNLP 2026 Findings, arXiv:2609.09554)** shows the "one monolingual
  whisper-large-v3 fine-tune per language" factory model scaling to 102 languages; the
  per-language FLEURS tables make it a usable catalog-filling resource, at a heavy
  per-entry size.
- **On-device TTS/ASR convergence** continues on litert-community (Qwen3-TTS, audio-in
  .litertlm bundles); nothing actionable for transcription beyond the VibeVoice probes.
- A TII "Falcon ASR" was announced in a news item (theopenweights.com) but no HF model
  was findable this run; unverified, watch only.
