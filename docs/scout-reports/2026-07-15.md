# Model Scout Report — 2026-07-15

## Executive Summary

12-day window since 2026-07-03. The landscape moved on three fronts, and one long-standing watch item resolved. **Three actionable items; no model displaces the current Distil-Whisper-IT + Parakeet TDT stack for Italian.**

1. **sherpa-onnx v1.13.4 tagged (Jul 7)** — bundles ORT 1.27.0 + the ASR text-postprocessing fixes (#3709 space-before-punctuation, #3711 leading-spaces) + a Qwen3 homophone-replacer hook (#3729). Free output-quality/hygiene win, low-risk AAR swap. **Recommendation: upgrade.**

2. **Cohere Transcribe is now sherpa-onnx-native** — the watch item resolves. `csukuangfj2/sherpa-onnx-cohere-transcribe-14-lang-int8-2026-04-01` (Apr 2026 packaging, verified) loads via the existing `OfflineRecognizer` path with `--cohere-transcribe-encoder/decoder`, 14 langs incl. **Italian**. The catch: it's a 2B model = **~2.65 GB int8** (2.7× the largest model we ship). The 07-03 report's "sherpa path closed" was a misread — PR #3456 *implemented* support (Apr), closing request #3442 as done.

3. **Gilbeot Korean-audio LoRA → `.litertlm` recipe** (HF: psymon/gilbeot-korean-audio-litertlm) is a complete, reproducible template for an **Italian-audio LoRA on our existing LlmTranscriptionBackend stack** (Korean STT CER 13.14% → 5.00% on-device). The most interesting LLM lead — a *technique*, not a drop-in model.

**Two corrections to prior-session assumptions** (verified this session): the test device is **Qualcomm SM7675 (Snapdragon 7+ Gen 3), not MediaTek** — so QNN/NPU work is *potentially* relevant to us (not irrelevant), though per-SoC binaries mean sherpa's shipped SM8850 QNN artifacts don't run on SM7675 directly. And the Nemotron `att_context_size` fix (#3732, merged Jul 8) is **correct but not a quality lever** — on-device test (2026-07-15) showed the fixed model works but Italian quality remains mediocre.

## ASR Model Findings

### Cohere Transcribe 14-lang int8 — NOW sherpa-native (watch item RESOLVED)
- **Source:** `https://huggingface.co/csukuangfj2/sherpa-onnx-cohere-transcribe-14-lang-int8-2026-04-01` · sherpa doc `https://k2-fsa.github.io/sherpa/onnx/cohere_transcribe/index.html`
- **Size:** ~2.65 GB int8 (decoder.int8.onnx 146 MB + encoder.int8.onnx 2.9 MB + **encoder.int8.onnx.data 2.5 GB** + tokens) — 2B-param Conformer encoder-decoder
- **Languages:** 14 incl. **Italian** (en, fr, de, it, es, pt, el, nl, pl, zh, ja, ko, vi, ar). Requires explicit language flag.
- **Last updated:** 2026-04-01 (model); sherpa runtime support landed shortly after.
- **Format:** ONNX int8, sherpa-packaged. **sherpa-onnx compatible: YES** (verified — doc shows working decode, RTF 0.135; uses `OfflineRecognizer` like our other backends).
- **Italian quality:** #1 on Open ASR Leaderboard (5.42% avg WER, English-centric metric). **Italian WER is on the model card only as an image — unverified numerically.** Needs VAD gate (eager to transcribe silence) — we already run VAD.
- **Score:** **6/10.** Recommendation: **Evaluate — but only if a 2.65 GB download is acceptable.** The size/quality ratio is poor for mobile where Italian is primary (Distil-IT gets ~4.3% Italian WER at 756 MB). Worth benchmarking on our eval set (now that the harness runs) only if leaderboard-prestige or non-Italian EU quality matters. Effort: medium (new backend via existing OfflineRecognizer pattern + R8 audit).

## LLM Model Findings

### Gilbeot Korean-audio LoRA → `.litertlm` — actionable TECHNIQUE
- **Source:** `https://huggingface.co/psymon/gilbeot-korean-audio-litertlm` (Kaggle Gemma 4 Good Hackathon, May 2026)
- **What it is:** Gemma 4 E2B-it + rank-8 Korean-audio LoRA, single 2.6 GB `.litertlm`. Audio-capable (grafts LoRA into the `audio_encoder_hw.tflite` USM Conformer). Korean STT CER **13.14% → 5.00%** on-device (S10e CPU).
- **Why it matters:** A complete, reproducible recipe to bake an **Italian-audio LoRA into our existing `LlmTranscriptionBackend`/`.litertlm` stack** — the same runtime we already run. Patcher is open (`tools/patch_gemma4_lora_requant.py`). Two documented gotchas: (1) vanilla PEFT 0.19 **silently skips** Gemma 4's `Gemma4ClippableLinear` audio layer — must use **Unsloth FastModel**; (2) trained on a 50h speaker-stratified elderly-speech subset.
- **Score:** **7/10.** Recommendation: **Evaluate (technique).** Highest-value LLM lead — but it's a training project (build an Italian-audio LoRA), not a drop-in download. Fits the existing `.litertlm` path; the Unsloth-FastModel requirement is the key constraint. Relevant to TASK-245 (fine-tune) thinking.

## Landscape Developments

**Cohere Transcribe sherpa unlock is the headline ecosystem event.** The model the 06-29/07-03 reports called "highest-impact missing Italian candidate, no sherpa path" now has a first-class sherpa path. The blocker shifted from *runtime* to *size* (2.65 GB) and *unknown Italian WER*. No distilled/smaller Cohere variant exists yet, though `CohereLabs/cohere-transcribe-arabic-07-2026` (Jul 11) signals Cohere is iterating — a smaller multilingual distill is plausible later.

**sherpa-onnx QNN investment is heavy — and relevant to us (device correction).** v1.13.4 + post-tag master is dominated by Qualcomm NPU exports (Parakeet TDT/CTC, Whisper, Nemotron, Moonshine). One scout agent dismissed this as "MediaTek device, no win" — **incorrect**: our Realme RMX3853 is **Qualcomm SM7675 (Snapdragon 7+ Gen 3)**, so QNN is *potentially* applicable. BUT QNN context binaries are per-SoC, and sherpa ships **SM8850** (and a few others) — **not SM7675**. So QNN remains a watch item (if SM7675 binaries appear), not actionable now. See TASK-247.

**INT8 is the standard for CPU ASR; INT4 is not production-ready.** Cohere int8 export: +0.22% WER (good). Cohere int4: +3.55% WER (unacceptable). Our int8 backends are on the right approach; don't chase int4 for ASR quality.

**No new Italian ASR model/benchmark/fine-tune in-window.** Common Voice Italian unchanged; no new Distil-Whisper-IT variant (large-v3/distil-v3 remain newest weights). The Italian ASR options remain: Distil-Whisper-IT (~4.3%, best), Parakeet TDT v3 multilingual (untested, promising), Parakeet TDT English-trained (5.4%, our default), Cohere Transcribe (untested Italian, large), Nemotron (mediocre per this session's test).
