# Model Scout Report — 2026-06-12

## Executive Summary

Short cycle (2 days since 06-10). **One landmark discovery**: NVIDIA released `nvidia/nemotron-3.5-asr-streaming-0.6b` on June 4 — a streaming multilingual ASR model with **5.23% Italian WER on FLEURS (LangID)**, **4.85% (auto-detect)**, outperforming the current Parakeet TDT 0.6b v3 (5.4%). csukuangfj has already exported it to sherpa-onnx format (657 MB int8 encoder) and merged native streaming Nemotron support into sherpa-onnx master (PR #3671, June 12) with Kotlin/Java bindings. This model covers **40 languages** (vs Parakeet's 25), has **built-in punctuation/capitalization**, **automatic language detection**, and uses cache-aware streaming that avoids redundant computation. **Requires sherpa-onnx v1.13.3** (not yet released) or building from master.

No new sherpa-onnx release (v1.13.2 at 30 days). The SmoothQuant Parakeet encoder (TASK-223) remains pending evaluation.

## ASR Model Findings

### NVIDIA Nemotron 3.5 ASR Streaming 0.6b — Landmark New Model (MAJOR NEW FINDING)

- **Source:** https://huggingface.co/nvidia/nemotron-3.5-asr-streaming-0.6b
- **Released:** June 4, 2026 | **Downloads:** 4,965
- **Architecture:** Cache-Aware FastConformer-RNNT with Language-ID Prompt conditioning
- **Parameters:** 600M (0.6B) — 24 encoder layers
- **Languages:** **40 language-locales** in 3 tiers:
  - **Transcription-ready (19):** en, es, fr, **it**, pt, nl, de, tr, ru, ar, hi, ja, ko, vi, uk
  - **Broad-coverage (13):** pl, sv, cs, nb, da, bg, fi, hr, sk, zh, hu, ro, et
  - **Adaptation-ready (8):** el, he, lt, sl, lv, mt, th, nn (need fine-tuning)
- **License:** OpenMDW-1.1 (permissive, commercial use)
- **Chunk sizes:** 80ms, 160ms, 320ms, 560ms, 1120ms (configurable at runtime, no retraining)
- **Key features:**
  - **Language auto-detection** with `target_lang=auto` — detects spoken language and emits language tag
  - **Built-in punctuation and capitalization** — no external PnC model needed
  - **Cache-aware streaming** — maintains encoder caches, eliminates redundant computation (unlike buffered streaming)
  - **Prompt-conditioned** — language ID fused with acoustic representation

- **Italian WER on FLEURS (1120ms chunk):**

  | Mode | Italian WER | Notes |
  |------|------------|-------|
  | LangID (`it-IT`) | **5.23%** | Better than Parakeet TDT v3 (5.4%) |
  | Auto-detect | **4.85%** | Competitive with Distil IT (4.3%) |

- **Comparison with Anti-Vocale's current ASR models on Italian FLEURS:**

  | Model | Italian WER | Size (total) | Languages | Streaming |

  | **Nemotron 3.5 Streaming (auto)** | **4.85%** | **~682 MB** | **40 langs** | **Yes** |
  | **Nemotron 3.5 Streaming (LangID)** | **5.23%** | **~682 MB** | **40 langs** | **Yes** |
  | Parakeet TDT 0.6b v3 | 5.4% | 464 MB | 25 EU langs | No |
  | Qwen3-ASR 0.6b | 12.2% | ~300 MB | 15 langs | No |

- **sherpa-onnx export (authoritative, by csukuangfj):**
  - Source: `csukuangfj2/sherpa-onnx-nemotron-3.5-asr-streaming-0.6b-{chunksize}-int8-2026-06-11`
  - Files (1120ms int8 variant):

    - `decoder.int8.onnx` — 15 MB

    - **Total: ~682 MB** (218 MB larger than Parakeet's 464 MB)
  - 8 variants uploaded: 80ms/160ms/560ms/1120ms × fp32/int8
  - File naming: **sherpa-onnx native format** — no conversion needed

- **sherpa-onnx integration status:**
  - **PR #3671 merged to master (June 12):** "Add multilingual Nemotron-3.5 streaming ASR support"
  - Includes: C API, CXX API, Dart/Flutter, **Kotlin/Java bindings**
  - Uses per-stream language strings (`"en"`, `"it"`, `"auto"`)
  - **Requires v1.13.3 or building from master** — not in v1.13.2

- **Score:** 9/10 (Italian quality: 9 — 5.23%/4.85% WER, better than Parakeet; Size: 7 — 682 MB int8 (218 MB larger than Parakeet, but within our model range); On-device: 9 — sherpa-onnx native format with Kotlin bindings already merged; Multilingual: 10 — 40 languages (15 more than Parakeet) with auto-detect; Maintenance: 9 — NVIDIA first-party, actively maintained, already in sherpa-onnx master)
- **Recommendation:** **EVALUATE — HIGHEST PRIORITY** — This is the most significant ASR model discovery for Anti-Vocale in the entire scout series. It outperforms the primary backend (Parakeet) on Italian WER, covers 60% more languages, has built-in punctuation and language detection, and is already natively supported in sherpa-onnx with Kotlin bindings. The streaming architecture also opens the possibility of real-time transcription display. The 218 MB size increase (464→682 MB) is acceptable given the quality and language coverage gains.

- **Integration path:**
  1. Wait for sherpa-onnx v1.13.3 (or build from master)
  2. Update `libs/sherpa-onnx.aar` to include Nemotron streaming support
  3. Create `NemotronStreamingDownloader.kt` and `NemotronStreamingModelManager.kt`
  4. Add streaming backend option (1120ms chunk for best quality, or configurable)
  5. Evaluate offline use: feed entire voice message as single chunk (1120ms variant with maximum right context)
  6. Add ProGuard keep rules for new backend classes
  7. Benchmark on real Italian voice messages vs Parakeet and Distil IT

- **Risks:**
  - Streaming model used in offline mode may behave differently than pure offline models — needs real-device testing
  - The cache-aware architecture requires sequential chunk processing — verify it handles full-file mode correctly
  - OpenMDW-1.1 license needs review for Play Store compliance (appears permissive but is not Apache/MIT)

## Landscape Developments

**NVIDIA Nemotron 3.5 ASR Streaming** is a landmark release for on-device ASR. The model combines several features that were previously available only in separate models:
1. **Streaming capability** with cache-aware inference (no redundant computation)
2. **40 languages** from a single model (vs Parakeet's 25)
3. **Built-in punctuation/capitalization** (Parakeet and Whisper don't include this natively)
4. **Language auto-detection** with `target_lang=auto`
5. **Better Italian WER** than Parakeet TDT v3 (5.23% vs 5.4%)

The fact that csukuangfj (sherpa-onnx maintainer) immediately exported the model and added native Kotlin bindings (PR #3671, merged within 8 days of NVIDIA's release) signals strong ecosystem support. The model uses the same FastConformer encoder family as Parakeet, meaning it should run efficiently on the same ARM64 hardware.

For Anti-Vocale specifically, the streaming architecture opens two integration paths:
1. **Offline mode (drop-in replacement):** Feed entire voice message as a single chunk using the 1120ms variant. This would replace Parakeet with better Italian quality and more languages.
2. **Streaming mode (new capability):** Process audio in chunks with real-time text display. This would enable progressive transcription UI where text appears as the audio plays.

The key blocker is **sherpa-onnx v1.13.3** — the Nemotron streaming support code is in master but not yet released. Anti-Vocale cannot integrate until the AAR is updated.
