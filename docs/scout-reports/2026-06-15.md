# Model Scout Report — 2026-06-15

## Executive Summary

**Two significant developments this cycle.**

1. **sherpa-onnx v1.13.3 RELEASED today (June 15)** — includes the multilingual Nemotron-3.5 streaming ASR support (#3671) that has been the gate across the last four reports. The Android AAR (`sherpa-onnx-1.13.3.aar`, 54.4 MB) is available. This unblocks the Nemotron int8 size-optimization path (fp32 ~2.5 GB → int8 ~682 MB).

2. **`pantinor/parakeet-tdt-0.6b-v3-smoothquant` is already in sherpa-onnx native format** (created June 6, your own repo) — `encoder.int8.onnx` (882 MB) + `decoder.int8.onnx` (11.8 MB) + `joiner.int8.onnx` (6.36 MB) + `tokens.txt`. The file naming matches exactly what `ParakeetModelManager` expects. **This effectively resolves TASK-223** (evaluate SmoothQuant sherpa-onnx compatibility) — the repackaging is done; TASK-224 (integrate) can proceed.

No new Italian Whisper fine-tunes. Nemotron 3.5 ecosystem continues expanding (CSTR GGUF now 346 downloads, +jeffpeng3 int4 dynamic) but all non-sherpa-onnx.

## Major Findings

### sherpa-onnx v1.13.3 — RELEASED (GATE CLEARED)

- **Source:** https://github.com/k2-fsa/sherpa-onnx/releases/tag/v1.13.3
- **Released:** June 15, 2026 (today)
- **Android AAR:** `sherpa-onnx-1.13.3.aar` (54.4 MB, sha256: `243ad797a3b6e75ebbeaf7a2ab4aec0777e7d71b730685abb762a120940b07b6`)
- **Relevant changes since v1.13.2:**
  - **#3671 Add multilingual Nemotron-3.5 streaming ASR support** (JulianPscheid) — Kotlin/Java/C/CXX/Dart bindings for the streaming Nemotron model Anti-Vocale already ships
  - #3647, #3669 OfflineDiacritization bindings (matiaslin)
  - #3617 build: allow overriding ONNX Runtime for mobile (abretonc7s)
  - #3678 Update iOS to use onnxruntime 1.26.0
  - #3645–#3670 — QNN/X-ASR work (Qualcomm NPU acceleration path; not Anti-Vocale's CPU path but signals maturing NPU support)
- **Impact for Anti-Vocale:** This is the gate that has been pending since 06-12. With v1.13.3, Anti-Vocale can:
  1. Update `libs/sherpa-onnx.aar` to v1.13.3
  2. Swap the Nemotron backend from fp32 (~2.5 GB) → csukuangfj2 int8 export (~682 MB) using native Kotlin streaming bindings
  3. Run pre-release R8 audit (per CLAUDE.md checklist) before shipping a release build
- **Recommendation:** **ACTION — upgrade to v1.13.3** is now unblocked. Bundles Nemotron streaming bindings + the int8 size-optimization path.

### pantinor/parakeet-tdt-0.6b-v3-smoothquant — sherpa-onnx Native SmoothQuant (RESOLVES TASK-223)

- **Source:** https://huggingface.co/pantinor/parakeet-tdt-0.6b-v3-smoothquant
- **Created:** June 6, 2026 (your own repo)
- **Format:** **sherpa-onnx native** — exactly the file set `ParakeetModelManager.REQUIRED_FILES` expects:
  - `encoder.int8.onnx` — 882 MB
  - `decoder.int8.onnx` — 11.8 MB
  - `joiner.int8.onnx` — 6.36 MB
  - `tokens.txt` — 93.9 kB
  - **Total: ~900 MB** (vs current Parakeet TDT v3 stock int8 ~464 MB — 436 MB larger, but fixes long-audio degradation)
- **Significance:** The SmoothQuant encoder (originally Olicorne's istupakov-format export) has been repackaged into sherpa-onnx naming. **TASK-223 (evaluate sherpa-onnx compatibility) is effectively done** — the model is in the correct format. TASK-224 (integrate) needs only `ParakeetDownloader`/`ParakeetModelManager` to point at this repo.
- **Note:** The 882 MB encoder is larger than Olicorne's 842 MB (reported 06-10) — likely a different packaging of weights or a slightly different SmoothQuant calibration. Worth verifying the encoder produces equivalent long-audio quality before shipping.
- **Recommendation:** **Update TASK-223 → resolved; proceed to TASK-224** (integrate into Parakeet backend, point downloader at this repo, evaluate removing 1s tail padding, test on real device).
