# Model Scout Report — 2026-04-26

## Executive Summary

First model scout run. No previous report to compare against. Key findings: **sherpa-onnx should be upgraded from v1.12.34 to v1.12.40** (6 releases behind, includes ONNX Runtime update and JNI UTF-8 fix). **Qwen3-ASR-1.7B** is now available in ONNX int4 (~700MB compressed) as a potential quality upgrade over the 0.6B variant. **Parakeet TDT v3 int4** variants are emerging from the community (30-40% smaller than int8). No new Italian-specific ASR models were found. No successor to Parakeet TDT v3 exists yet.

## ASR Model Findings

### Qwen3-ASR 1.7B ONNX (NEW — larger variant)
- **Source:** https://huggingface.co/andrewleech/qwen3-asr-1.7b-onnx
- **Size:** ~700MB compressed (int4 quantization), ~1.4GB fp16
- **Languages:** 52 languages including Italian
- **Last updated:** 2026-03-30
- **Format:** ONNX (encoder.int4.onnx, decoder_step.int4.onnx, decoder_init.int4.onnx)
- **sherpa-onnx compatible:** Uncertain — uses separate conv_frontend architecture like the 0.6B, may need sherpa-onnx updates
- **Italian quality assessment:** Unknown — Qwen3-ASR family claims SOTA on multilingual benchmarks but no Italian-specific WER data available
- **Score:** 6.8/10 (Italian quality unknown 3/5, size acceptable 3/5, feasible 4/5, multilingual 5/5, maintained 4/5)
- **Recommendation:** **evaluate** — benchmark Italian WER against Parakeet before considering
- **Effort to integrate:** Medium — similar architecture to existing 0.6B backend but needs size verification and performance testing on device
- **Notes:** Larger model may not fit the on-device size budget. The 0.6B variant already in the app is more practical.

### Parakeet TDT 0.6b v3 ONNX int4 (NEW — community quantization)
- **Source:** https://huggingface.co/efederici/parakeet-tdt-0.6b-v3-onnx-int4
- **Size:** ~280-350MB estimated (int4 encoder, int8 decoder/joiner)
- **Languages:** 25 EU languages including Italian (same model, different quantization)
- **Last updated:** 2026-04-17
- **Format:** ONNX int4 encoder + int8 decoder/joiner
- **sherpa-onnx compatible:** Uncertain — int4 quantization not standard in sherpa-onnx transducer pipeline. Would need testing.
- **Italian quality assessment:** Should be comparable to int8 with minor quality loss from int4 quantization, but unverified
- **Score:** 7.2/10 (Italian quality likely similar 4/5, size excellent 5/5, feasibility uncertain 3/5, multilingual 4/5, community-maintained 3/5)
- **Recommendation:** **watch** — int4 could reduce Parakeet from 464MB to ~300MB, but compatibility with sherpa-onnx is unproven
- **Effort to integrate:** Medium — needs sherpa-onnx int4 support verification, then drop-in replacement
- **Notes:** 118 downloads suggests community interest. The encoder file is `encoder-model.int4.onnx` which may need ONNX Runtime int4 support (available since ORT 1.24+).

## Landscape Developments

### Moonshine v2 — Ultra-compact edge ASR
Moonshine v2 introduces 26MB ASR models with streaming support. Remarkable size but currently **English/Spanish/Mandarin/Japanese/Korean/Vietnamese/Ukrainian/Arabic only — no Italian**. Already integrated in sherpa-onnx. If Italian support arrives, this would be a game-changer for on-device ASR at 26MB.

### Qwen3-ASR — Strongest new contender
Qwen3-ASR (52 languages, 0.6B and 1.7B variants) claims SOTA open-source ASR quality. Anti-Vocale already has a `Qwen3AsrBackend.kt` for the 0.6B variant. The 1.7B variant is now available in ONNX int4 but may be too large for on-device use.

### Parakeet ecosystem stable
No Parakeet TDT v4 or successor architecture announced. The v3 multilingual model remains current. Community is producing alternative quantizations (int4). Parakeet TDT 0.6b v2 sits atop the HuggingFace OpenASR Leaderboard for English.

### sherpa-onnx remains dominant
No credible on-device ASR runtime competitor has emerged. sherpa-onnx continues to add model support (Moonshine, Qwen3-ASR, SenseVoice, Nemotron streaming). The upgrade to v1.12.40 is straightforward and recommended.
