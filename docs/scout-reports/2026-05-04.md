# Model Scout Report — 2026-05-04

## Executive Summary

Two days since last report. **LiteRT-LM v0.10.2 is available** (project on 0.9.0) with improved Gemma 4 support — this is the most actionable upgrade since the `.litertlm` format is our working audio path (we already ship GEMMA_3N_E2B, GEMMA_3N_E4B, GEMMA_4_E2B, GEMMA_4_E4B via `ModelDownloader`). ## Landscape Developments

### Argmax Parakeet Android SDK validates on-device Parakeet
Argmax Inc launched a commercial Android SDK (`argmaxinc/parakeetkit-litert-pro`) running Parakeet TDT 0.6B v2 on-device via LiteRT with NPU acceleration. Google's AI Edge blog documented the approach: Ahead-Of-Time (AOT) compilation for NPU, models delivered via Google Play's AI Packs. Heidi Health uses it for live on-device medical transcription. **This confirms our architectural choice** — Parakeet on Android via optimized inference is proven in production. The AI Pack delivery pattern (on-demand model downloads via Play Store) is worth studying for reducing initial app size.

### distil-whisper-v3.5 emerges as new default
distil-large-v3.5 is now the default in faster-whisper: 756M params, 7.08% WER (vs 7.53% for distil-large-v3), ~6.3x faster than full large-v3. This is a multilingual model. **No Italian-specific fine-tune or ONNX export exists yet.** If the community produces a distil-large-v3.5-it (Italian fine-tune + ONNX export), it could marginally improve over our current distil-large-v3-it. Low priority — our Italian distil model already performs well.

### Parakeet v3 language fine-tuning proven
The Brazilian Portuguese fine-tune (`calneymgp/parakeet-tdt-0.6b-v3-ptBR-TAGARELA-onnx-int8`) proves Parakeet TDT 0.6b v3 is fine-tunable for specific languages with direct ONNX int8 export. This pattern could be replicated for Italian if training data (Italian voice messages with transcripts) were available. A hypothetical `parakeet-tdt-0.6b-v3-it-ONNX-int8` would combine the speed/size advantages of Parakeet with Italian-specific quality, potentially matching or exceeding our Whisper distil-large-v3-it.
