## Correction to 06-12 Report

The 06-12 report framed NVIDIA's Nemotron 3.5 ASR Streaming as a "landmark new model to integrate." This was **incorrect** — Anti-Vocale already integrates this exact model as a secondary backend:

- **`NemotronDownloader.kt`** downloads from `pantinor/nemotron-3.5-asr-streaming-0.6b-sherpa`
- **`NemotronModelManager.kt`** validates `encoder.onnx` + `encoder.onnx.data` + `decoder.onnx` + `joiner.onnx` + `tokens.txt`
- **Format: fp32, ~2,593 MB** total
- **Known issue:** word skipping on Italian (per memory: "blankPenalty 1.0 slightly helps, not a Distil-IT replacement; ships as secondary backend")

The accurate takeaways from the 06-12 findings:
1. **csukuangfj2's int8 export** (~682 MB) of the same model is a **4x smaller** alternative to Anti-Vocale's current fp32 (~2,593 MB) — potential **~1.9 GB storage savings** if Italian quality holds at int8.
2. **sherpa-onnx PR #3671** added native streaming Nemotron Kotlin bindings — this is the runtime-support change, not a new model.
3. The Italian WER benchmarks (5.23%/4.85%) are NVIDIA's FLEURS numbers for the model Anti-Vocale already ships; the word-skipping issue observed on-device is a real-world degradation not reflected in those FLEURS-clean-audio numbers.
