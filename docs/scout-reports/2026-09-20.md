## ASR Model Findings

### Orukeet (oruk/orukeet)
- **Source:** https://huggingface.co/oruk/orukeet (arXiv:2609.10054; Oruk AI + Stanford + Cambridge + OpenWhispr)
- **Size:** 671.6 MB extracted int8 (486.8 MB tar.bz2); +45 percent vs the shipped Parakeet v3 int8 (464 MB), still under the 1 GB bar
- **Languages:** 25; 23 shared with ours; drops Turkish and Norwegian, adds Lithuanian and Maltese
- **Last updated:** 2026-09-19 (created 09-09; actively revised)
- **Format:** ONNX int8 in the standard Parakeet TDT v3 sherpa layout (encoder 653.2 MB, decoder 11.8 MB, joiner 6.4 MB, tokens.txt, bpe.vocab), packaged as `onnx/sherpa-onnx-orukeet-v0.1.0-int8.tar.bz2`
- **sherpa-onnx compatible:** yes, first-party export; loads with the existing offline transducer loader; the pinned 1.13.8 eval venv already runs this family
- **Italian quality assessment:** FLEURS it_it WER 2.43 (Parakeet) to 2.09 (Orukeet), 865 clips, minus 13.9 percent relative, from the repo's paired evidence CSV (`evidence/standard-asr-r3-20260908/scores.csv`). Self-published but paired and auditable. Caveats: FLEURS is clean read speech, not voice messages (our clean-to-real Parakeet delta is 4.3 to ~10 percent, so the transfer must be measured on our harness); Greek regressed badly (21.1 to 30.8) and French slightly, so it is not uniformly better; checkpoint selection used English LibriSpeech test-other, disclosed.
- **Score:** 4.2/5 (Italian 4, size 4, feasibility 5, breadth 4, maintenance 4)
- **Recommendation:** evaluate now on the desktop harness against shipped Parakeet and Distil-IT baselines
- **Effort to integrate:** low (eval); low-medium (catalog entry with sha256 pin, CC BY-SA 4.0 attribution via NOTICE.md, device verify, and a tr/no coverage decision)
- **Notes:** weights CC BY-SA 4.0 (copyleft, stricter than the CC-BY-4.0 base; OpenWhispr already ships it in an app, so distribution practice exists). No claimed speed penalty on desktop (390 vs 428 ms median per file); on-device RTF unmeasured.

### VibeVoice-ASR-Streaming-1.5B (litert-community)
- **Source:** https://huggingface.co/litert-community/VibeVoice-ASR-Streaming-1.5B (created 2026-09-17; the 09-16 watch-list trigger fired)
- **Size:** 1.99 GB int4 bundle (2.77 GB int8 desktop)
- **Languages:** 10 tags including Italian; card benchmarks are English-only (streaming WER 7.1-7.8 vs 2.68 non-streaming BitNet)
- **Last updated:** 2026-09-17
- **Format:** LiteRT-LM bundle; measured on litertlm 0.16.1 (card says 0.17.1 transcripts byte-identical)
- **sherpa-onnx compatible:** no (no sherpa conversion exists)
- **Italian quality assessment:** NOT_FOUND (tagged, unmeasured)
- **Score:** 2.2/5 (Italian 2, size 2, feasibility 1, breadth 4, maintenance 4)
- **Recommendation:** watch, sequenced behind the litertlm-android bump probe (TASK-580)
- **Effort to integrate:** high
- **Notes:** device evidence on card (Galaxy S26 RTF 0.2-0.4 int4, 1483-2511 MB peak RAM; Pixel 8a CPU-only). It is a protocol, not a prompt: multi-turn conversation host, 3.467 s windows / 2.933 s advance, 4-frame look-ahead, 24 kHz framing, speaker-label stripping, ~2.5 min KV budget per conversation; the card states a one-clip-per-message host transcribes wrong. A new subsystem, not a backend swap; unique value is streaming speaker-attributed ASR on a runtime we already ship.

## LLM Model Findings

Dedicated scout run this morning, same day: `claudedocs/research_small_llm_scout_2026-09-20.md`. Verdict summary: Gemma 4 E2B (2588 MB .litertlm, apache-2.0, official, on pinned litertlm 0.13.1) remains the right default; the "better" tier already ships in-app as the E4B variant with zero code; Qwen3.5-4B is the only clear quality winner but is GGUF-only, slightly larger, and needs the dormant llamabro fork; SmolLM3-3B (1915 MB) is the best size-down but a 2025-generation tier; MiniCPM5 is blocked by litertlm >= 0.16 (0.16.1 crashed on device, upstream #3334). The gate for everything non-Gemma is the litertlm-android bump, tracked as TASK-580 (0.17.1 is published and Maven-resolvable; the #3334 thread has a new consumer data point: a clean one-turn text probe on 0.17.0 with declared coroutines deps).

## Landscape Developments

- **Canary-1b-v2 eval correction.** The 09-16 recommendation 1 (desktop-harness Italian eval of the Sarphix canary-1b-v2 int8 export) is INVALID as written: `from_nemo_canary` hardcodes lang2id to en/es/de/fr (our issue #3961, PR #3962 open), so an Italian run on pinned 1.13.8 silently decodes English. The eval is gated on #3962 merging and shipping, or on locally patching the eval-side runtime. Orukeet now also gives that eval a faster cheap comparator.
- **Smart-Turn-v3.2-ONNX** (soniqo, 10.6 MB int8, BSD-2-Clause, 32 languages including Italian, android-tagged): proposed for sherpa VAD end-of-utterance detection in open PR #3956. Relevant to Nemotron live-view boundaries and VAD-aligned chunking; watch until merged and shipped. Boundary quality unassessed.
- **Streaming ASR-LLM distillation** (arXiv:2609.20121, 09-17): alignment-path distillation into interleaved streaming ASR-LLMs, 16.6 percent relative error reduction. Signal only; we train nothing and our streaming backend is a FastConformer transducer.
