# Model Scout Report — 2026-05-24

## Executive Summary

14 new models scanned, 1 major new capability discovered. The most significant finding is **Gemma 4 audio LoRA grafting** — a proven pattern (deployed for Korean) that fine-tunes the Gemma 4 E2B audio encoder with LoRA and packages it as .litertlm, reducing STT CER from 13% to 5%. This approach could be applied to Italian to create a unified LLM-based ASR path. On the ASR front, `onnx-community/cohere-transcribe-03-2026-ONNX` now provides official int8/q4 quantized ONNX exports with Italian support (though not yet in sherpa-onnx). No new Italian-dedicated Whisper or Parakeet models. All frameworks are current — no upgrades needed.

## LLM Model Findings

### psymon/gilbeot-korean-audio-litertlm (BREAKTHROUGH PATTERN)
- **Source:** https://huggingface.co/psymon/gilbeot-korean-audio-litertlm
- **Size:** 2.6 GB (Gemma 4 E2B base + Korean audio LoRA)
- **Languages:** Korean, English
- **Last updated:** 2026-05-18
- **Format:** .litertlm (LiteRT-LM)
- **Audio support:** Yes — Korean audio LoRA grafted into Gemma 4 E2B audio encoder
- **Italian quality assessment:** N/A — Korean model. But the METHODOLOGY is directly applicable to Italian.
- **Score:** 9/10 (as a pattern) — this proves the audio LoRA grafting approach works end-to-end
- **Recommendation:** **evaluate for methodology** — this is the most important finding of this scout. The approach: (1) fine-tune LoRA on Gemma 4 E2B audio encoder using Italian speech data, (2) per-row dequantize INT4 weights, add LoRA delta, re-quantize, (3) package as .litertlm. Result: Korean STT CER dropped from 13% to 5%. Same approach could improve Italian transcription significantly.
- **Effort to integrate:** high — requires fine-tuning pipeline, Italian speech dataset, LoRA grafting tooling
- **Notes:** Uses `flutter_gemma` plugin with `SetScopedLoraFile` for runtime LoRA application. The approach reduces memory by loading LoRA deltas on top of base INT4 weights rather than shipping a full fine-tuned model. 11 downloads, 0 likes — very new but proven results.

## Landscape Developments

**Gemma 4 audio LoRA grafting is now proven and deployed.** The Korean `gilbeot` project demonstrated that fine-tuning Gemma 4 E2B's audio encoder with LoRA, grafting into INT4 weights, and packaging as .litertlm achieves significant quality improvements on-device. Multiple French and English LoRA fine-tunes have followed. This is the most promising path for creating a high-quality Italian-specific ASR model that runs through our existing LiteRT-LM backend. The approach avoids shipping a full fine-tuned model — instead, LoRA deltas are applied at runtime on top of base INT4 weights.

**IBM Granite Speech 4.1** (released 2026-05-21) introduces a non-autoregressive (NAR) 2B-param ASR model for EN/FR/DE/ES/PT. No Italian support, but the NAR architecture could influence future edge-optimized models. ONNX export already exists.

**Parakeet streaming matures.** sherpa-onnx v1.13.2 now exports NeMo unified streaming 0.6b models to ONNX with buffered RNNT paths. All streaming variants remain English-only, but the infrastructure is in place if NVIDIA releases multilingual streaming models.

**Cohere Transcribe ONNX expansion.** The official onnx-community export now offers q4 and q4f16 quantization variants alongside int8, making the model more accessible for size-constrained deployments. However, sherpa-onnx hasn't merged the custom decoder integration yet.
